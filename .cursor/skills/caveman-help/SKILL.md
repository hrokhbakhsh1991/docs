# caveman-help

| Cmd | Effect |
|-----|--------|
| `/caveman lite\|full\|ultra` | intensity |
| `/caveman wenyan-*` | classical CN |
| `stop caveman` / `normal mode` | off |
| caveman-compress | shrink long text |
| caveman-commit | conventional short commit |
| caveman-review | terse review |
| cavecrew | find symbol, no dump |

Default this repo: **ultra**. Heavy Vercel/UI skills off until named.
