# caveman-compress

Goal: fewer tokens in **context and replies**. Substance stay.

## Do

- Quote shortest decisive lines only (error, signature, invariant).
- Long AGENTS/rules/docs: 5–12 bullets max, then stop.
- Never paste a skill/rule body into chat "for completeness".
- Tool output: keep fail line + 1–2 neighbors. Drop stack noise.

## Don't

- Compress code you are about to edit (need exact text).
- Compress security warnings or irreversible confirmations.
- Invent abbreviations.

Exempt from "write normal prose" boundary: compressed summaries of memory/rules **are** the product.
