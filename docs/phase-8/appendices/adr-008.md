## Context

Phase 7 closed **Platform DoD** (second workspace, urban minimal E2E, router, adversarial RLS). Phase 8 must deliver **legacy Urban product surface** without `platform-core` creep.

## Decision

1. **Option A — Product Parity** is the primary epic: port catalog, registration, settings into `@app-tour/workspace-urban` and trunk `apps/*`.
2. **Option E — Silo tier** is a **subset** hardening epic in subphase **8.3** only — enterprise opt-in, not default for all tenants (ADR-007 carryover).
3. **Single-Owner auth** (DEC-P8-001) gates all urban configuration mutations before product HTTP bodies ship (8.1 before 8.2).

## Consequences

| Positive                                                      | Negative                                  |
| ------------------------------------------------------------- | ----------------------------------------- |
| Clear separation Platform DoD (P7) vs Product Parity DoD (P8) | Two parallel tracks after 8.2 (8.3 ∥ 8.4) |
| Generic resolver pattern preserved                            | Silo URL wiring deferred until 8.3        |
| Doc-first covenant enforced per subphase                      | ERIP COP required for 8.1–8.3 before code |

## Compliance

- INV-P8-001: no urban product diff in `packages/platform-core`
- INV-P8-003: no urban → denali rail
- MAP §22 reviewed at 8.0 entry
