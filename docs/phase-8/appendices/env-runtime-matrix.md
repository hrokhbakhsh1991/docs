> `@app-tour/workspace-urban` is **env-agnostic** (no `process.env` reads in `packages/workspaces/urban/**`). Urban operation depends on **host runtimes** (`apps/api`, `apps/web`, `tenant-kernel`) and **CI smoke** profiles below. Target consumer paths name **8.x implementation modules** — absent on trunk until the listed subphase lands.

---

## Environment profiles

| Profile         | `NODE_ENV`                | Urban plugin load                     | Postgres                                                                 | Redis rate limits                                     | Dev bearer / web session                           |
| --------------- | ------------------------- | ------------------------------------- | ------------------------------------------------------------------------ | ----------------------------------------------------- | -------------------------------------------------- |
| **Development** | `development`             | `lazy-urban-plugin.ts` dynamic import | Optional — static `DEV_TENANTS` when `DATABASE_URL` unset                | Optional — limiter disabled if `REDIS_URL` unset      | `ALLOW_DEV_WEB_SESSION=true` for host-map e2e only |
| **Staging**     | `production` or `staging` | Same as prod path                     | **Required** — `DATABASE_URL` + migrations `004_urban_product_delta.sql` | **Required** if `TENANT_RATE_LIMIT_ENABLED≠false`     | **Forbidden** — JWT only                           |
| **Production**  | `production`              | Same                                  | **Required** + RLS                                                       | **Required** — `assertProductionRedisUrl` fail-closed | **Forbidden** — `assertAuthEnvironmentIntegrity`   |

**Boot order (all profiles):** `assertAuthEnvironmentIntegrity` → `assertStaticTenantRegistryRuntime` → `assertProductionRedisUrl` (prod) → urban route registration (8.2) → `TenantConnectionRouter` (8.3).

## Redis key contracts (urban surfaces)

| Route                       | Bucket key pattern (when `REDIS_URL` set)             | Env cap source                                              |
| --------------------------- | ----------------------------------------------------- | ----------------------------------------------------------- |
| `GET /urban/catalog`        | `ratelimit:{tenantId}:pool:GET:/urban/catalog`        | `URBAN_CATALOG_THROTTLE_RPM` or `RATE_LIMIT_POOL_RPM` (120) |
| `POST /urban/registrations` | `ratelimit:{tenantId}:pool:POST:/urban/registrations` | `URBAN_REGISTRATION_THROTTLE_RPM` (30)                      |
| `GET /urban/settings`       | `ratelimit:{tenantId}:{tier}:GET:/urban/settings`     | `URBAN_SETTINGS_THROTTLE_RPM` (60)                          |

Silo tier replaces `pool` with `silo` in key segment when `TenantConnectionRouter` resolves `tier=silo` (8.3).

## HTTP validation status (normative)

| Condition                                                                                            | HTTP status | Body `code` / `error` prefix  | Mapper                                                                        |
