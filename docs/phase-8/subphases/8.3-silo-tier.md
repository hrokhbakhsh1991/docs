## 1. Behavioral Objective

Integrate **enterprise silo tier** for Urban tenants using Phase 7 `TenantConnectionRouter` — production wiring, not stub:

| Capability                   | Detail                                                                                              |
| ---------------------------- | --------------------------------------------------------------------------------------------------- |
| **DDL applied**              | `tenant_routes` table per TENANT-ROUTER-SPEC                                                        |
| **Router implementation**    | `TenantConnectionRouter.resolveRoute(tenantId)` returns pool default or silo `databaseUrl` override |
| **API consumption**          | `apps/api` obtains DB connections via router — **no** per-handler `process.env` silo URLs           |
| **Urban enterprise fixture** | Documented test tenant with `tier: silo` exercises urban catalog path on dedicated route            |
| **Fail-fast**                | Misconfigured silo row (missing URL when tier=silo) throws deterministic error                      |

**Single-Owner / INV-P8-007:** Silo provisioning is **platform ops / Architect fixture** — not member-facing. Urban owner settings on silo tenant still require owner role (8.1).

**Forbidden:** Silo as default for all tenants (P8-F-020 · ADR-007).
