## 1. Behavioral Objective

Prove **end-to-end Product Parity** for Urban flows across web + API + plugin:

| Capability              | Detail                                                                                |
| ----------------------- | ------------------------------------------------------------------------------------- |
| **Public catalog**      | Anonymous user browses urban tenant catalog — 200 + tenant-scoped data                |
| **Registration intake** | Public POST registration/waitlist — throttled · persists via plugin validation        |
| **Owner settings**      | Workspace **Owner** session accesses settings; **member** session denied (INV-P8-007) |
| **Canonical SoT**       | Tour/register payloads round-trip canonical document — no dual-write                  |
| **Cross-layer**         | Web → API → Prisma/RLS path with real `workspace_type: urban` tenant                  |

**Smoke matrix ID:** SMK-P8-01 (catalog) · SMK-P8-02 (register) · SMK-P8-03 (owner settings) · SMK-P8-04 (member denied settings).
