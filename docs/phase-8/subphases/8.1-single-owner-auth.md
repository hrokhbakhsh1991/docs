## 1. Behavioral objective

Implement **Urban Single-Owner** auth before any 8.2 product route body ships. All urban **configuration mutations** (settings, catalog admin, publish/unpublish, tour publish-field patches) require `isWorkspaceOwner(context) === true`. `role=admin` is **not** elevated on urban owner surfaces (DEC-P8-001).

| Deliverable     | Target path                                                                        |
| --------------- | ---------------------------------------------------------------------------------- |
| Grant           | `packages/workspace-sdk/src/auth/tenant-auth-grants.ts` — `isWorkspaceOwner`       |
| TenantAuthz API | `packages/workspace-sdk/src/auth/tenant-authz.ts` — `canPerformUrbanOwnerMutation` |
| API gate        | `apps/api/src/urban/require-workspace-owner.ts` — `assertWorkspaceOwner`           |
| API error       | `apps/api/src/urban/urban-owner-required.error.ts` — `URBAN_OWNER_REQUIRED`        |
| Error map       | `apps/api/src/middleware/error-interceptor.ts` — 403 handler                       |
| Web gate        | `apps/web/src/urban/urban-settings-access.ts` — `canLoadUrbanSettings`             |
| Route matrix    | `docs/phase-8/appendices/URBAN-ROUTE-MATRIX.md` — **frozen at 8.1**                |

**Out of scope 8.1:** catalog HTTP handlers, registration persist, `lazy-urban-plugin.ts`, `packages/workspaces/urban` registry extensions — **8.2 only**.

**In scope 8.1 (auth rail):** tour publish-field gate (`urban-tour-publish-field-gate.ts` · `TOURS-PUBLISH-FIELD-GATE.md` · `urban-tours-bypass-gate.spec.ts`) — owner-only PATCH field detection on `/tours/{id}`, not catalog HTTP.

## 2. Auth pipeline (mandatory order)

```text
resolveTenantContextFromRequest(req)          # tenant-kernel/tenant-kernel.ts
  → resolveWorkspaceTypeForTenant(tenantId) # tenant/resolve-workspace-type.ts
  → buildTenantAuthz(auth)                    # workspace-sdk
  → assertWorkspaceOwner({ auth, workspaceType, surface })  # urban/require-workspace-owner.ts
  → runWithHttpRequestContext(req, auth, …)   # http/bind-request-context.ts
  → handler business logic
```

Owner assertion runs **before** `runWithHttpRequestContext` so denied actors do not consume rate-limit or write-concurrency budget.
