## 1. Behavioral Objective

Port **legacy Urban product surface** into trunk plugin architecture:

| Capability                | Detail                                                                                             |
| ------------------------- | -------------------------------------------------------------------------------------------------- |
| **Extended urban plugin** | Registry, composites, validation hooks for catalog + registration fields — extends Phase 7.1 shell |
| **API HTTP surface**      | Public catalog list/detail; registration intake — `validate(plugin, canonical)` on persist         |
| **Web surface**           | Catalog pages, registration flow, owner-only settings shell (auth from 8.1)                        |
| **Plugin bootstrap**      | `getUrbanWorkspacePlugin()` in API registry; `lazy-urban-plugin.ts` sole web import path           |
| **Type binding**          | `urban` → `urban` plugin in `DEFAULT_WORKSPACE_TYPE_BINDINGS` (doc-first SDK change)               |
| **Genericity**            | Zero diff in `packages/platform-core`; no Denali rail (INV-P8-003)                                 |

**INV-P8-007 carryover:** Settings/catalog **admin** mutations remain owner-only — 8.2 must not bypass 8.1 guards.

**Forbidden in urban package:** Finance hooks, MinIO (DEC-P7-002 carryover).
