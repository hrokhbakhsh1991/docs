# Subphase 10.3 — HTTP workspace route registrar (urban pilot)

> **Phase:** 10.3 · **Status:** DONE (S1–S3)  
> **Goal:** `app.ts` contains no inline `/urban/*` dispatch; handlers live in `@app-tour/workspace-urban/http`.

## Contract

| Type | Location |
| ---- | -------- |
| `WorkspaceHttpRouteDescriptor` | `apps/api/src/http/workspace-http-types.ts` |
| Urban route table | `apps/api/src/http/urban-workspace-routes.ts` (derived from `URBAN_HTTP_ROUTE_MANIFEST`) |
| Manifest bridge | `apps/api/src/http/workspace-route-manifest-bridge.ts` |
| Registrar | `apps/api/src/http/workspace-route-registrar.ts` |
| Handler implementations | `packages/workspaces/<id>/src/http/` |
| Handler loaders | `apps/api/src/http/workspace-http-handler-loaders.generated.ts` (`loadHandlersFromPackage: true`) |
| Host wiring | `apps/api/src/http/configure-urban-http-host.ts` (urban) · product hosts per workspace |
| API shims | **removed** — no `apps/api/src/urban/**` on trunk |

## Host ports (DEC-P10-003 sketch)

Workspace handlers call trunk only through `configureUrbanHttpHost()`:

- HTTP envelope: `runWithHttpRequestContext`, `sendJson`, `handleHttpError`
- Tenant: `resolveWorkspaceTypeForTenant`, `resolveTenantContextFromRequest`
- Settings persist: `resolveTenantThemeJsonById`, `persistTenantTheme`
- Registration: idempotency + `assertPublicRegistrationThrottle` + capacity decision (host-injected from `apps/api/src/registrations/**`)
- Tours: `resolveTourStore` (Prisma adapter stays in API)

## Dispatch flow

```text
dispatchRequest → tryDispatchWorkspaceRoutes → workspace-urban/http handlers
```

## Tour-write bindings (P4-T13)

Manifest `tourWrite` (urban) drives `apps/api/src/tours/workspace-tour-write-bindings.generated.ts`. `workspace-tour-write-dispatch.ts` builds lookup maps from generated bindings — no hardcoded workspace id strings in host dispatch.
