# Subphase 10.1 — Outbox side-effect dispatcher

> **DEC:** DEC-P10-002 · **Status:** DONE (S1–S3)  
> **Goal:** `outbox-relay.ts` imports no `denali-finance/` module.

## Design

After `publishDomainEvent` in `publishClaimedOutboxRow`, the host calls:

```text
dispatchTourCreatedOutboxSideEffects(row)
```

Implementation (`apps/api/src/workspace/workspace-tour-created-dispatcher.ts`):

1. No-op unless `domainEventId` is present (relay already filters event type).
2. Resolve `workspace_type` via `resolveWorkspaceTypeForTenant`.
3. **Phase 1.8 Step 1:** when the workspace is registered for finance event reaction, call `processWorkspaceFinanceTourCreatedRow` (finance capability → reaction registry → workspace adapter). Do **not** call Denali `runTourCreatedFinanceSideEffect` from the dispatcher.
4. Remaining `WORKSPACE_OUTBOX_SIDE_EFFECT_BINDINGS` entries (non–`dispatchVia: financeEventReaction`) still run for future non-finance side effects.
5. Prisma `OutboxWriter` / processed-claim stay host-injected into the Denali adapter via `registerTourCreatedFinanceSideEffectDeps`.

## Files

| File | Role |
| ---- | ---- |
| `workspace/workspace-outbox-row-context.ts` | Minimal row type for side effects (decoupled from Prisma) |
| `workspace/workspace-tour-created-dispatcher.ts` | Host dispatch — sole caller from relay |
| `denali-finance/tour-created-finance-side-effect.ts` | Plugin handler + Prisma adapter (S3) |
| `outbox/outbox-relay.ts` | Calls dispatcher; no `denali-finance` import |

## S4 — Manifest-generated outbox bindings (P1-T12)

`workspace.manifest.json` `events[]` drives `apps/api/src/workspace/workspace-outbox-side-effects.generated.ts`.

- **`hostSideEffect.dispatchVia: "financeEventReaction"`** (Denali TourCreated): codegen re-exports register/run symbols for adapter IO + tests, but **does not** put Denali `run*` into `WORKSPACE_OUTBOX_SIDE_EFFECT_BINDINGS`. Production dispatch is ownership of the finance reaction registry.
- Other events without `dispatchVia` still emit binding `run` entries for the dispatcher loop.

Regenerate: `pnpm run generate:workspace-registry`.
