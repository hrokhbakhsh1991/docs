# Subphase 10.1 — Outbox side-effect dispatcher

> **DEC:** DEC-P10-002 · **Status:** DONE (S1–S3)  
> **Goal:** `outbox-relay.ts` imports no `denali-finance/` module.

## Design

After `publishDomainEvent` in `publishClaimedOutboxRow`, the host calls:

```text
dispatchTourCreatedOutboxSideEffects(row)
```

Implementation (`apps/api/src/workspace/workspace-tour-created-dispatcher.ts`):

1. No-op unless `eventType === "TourCreated"`.
2. Resolve `workspace_type` via `resolveWorkspaceTypeForTenant`.
3. For `denali` only: `runTourCreatedFinanceSideEffect` → `handleTourCreatedLedgerEvent` (`@app-tour/workspace-denali`) with Prisma `OutboxWriter` injected.
4. `processDenaliFinanceTourCreatedRow` remains a thin wrapper for integration tests.
5. Prisma `OutboxWriter` stays in API adapter until Phase 4.

## Files

| File | Role |
| ---- | ---- |
| `workspace/workspace-outbox-row-context.ts` | Minimal row type for side effects (decoupled from Prisma) |
| `workspace/workspace-tour-created-dispatcher.ts` | Host dispatch — sole caller from relay |
| `denali-finance/tour-created-finance-side-effect.ts` | Plugin handler + Prisma adapter (S3) |
| `outbox/outbox-relay.ts` | Calls dispatcher; no `denali-finance` import |
