## Guest workspace scaffold (`--guest`, PF-3)

`pnpm run workspace:create -- <id> --guest` writes a package that satisfies **guest conformance L3** after `pnpm run generate:workspace-registry`:

| Manifest block | Purpose |
| -------------- | ------- |
| `http` + `httpRoutes` | Catalog list/detail + registration POST paths (`GET /{id}/catalog`, `GET /{id}/catalog/:tourId`, `POST /{id}/registrations`) |
| `catalogPresentation` | Marketing list/detail gates (defaults: `cityFilter: false`, detail sections off) |
| `catalogRegistrationFlow` | Compose mode with `reuseAuthStepsFrom: "shared"` + local `intake`/`done` React steps |
| `memberProfile` | Portal `/me/profile` field visibility (minimal: editable `displayName`, read-only `email`) |
| `devBootstrap.pluginTenantIds` | Dev-only tenant UUID → plugin map (deterministic hash per workspace id) |
| `devBootstrap.smokeTenant` | Exports `${CONST}_SMOKE_TENANT_ID` / `${CONST}_SMOKE_SUBDOMAIN` from package root |
| `guestThemeStylesheets.marketing` | Placeholder marketing theme CSS |

Stub TypeScript/React files are included so `@app-tour/workspace-<id>` builds and codegen imports resolve (`/catalog-registration-flow`, `/http`, smoke exports). HTTP handlers return `501 WORKSPACE_GUEST_STUB` until product logic lands.

Verification after scaffold:

```bash
pnpm install
pnpm run generate:workspace-registry
pnpm run guard:workspace-registry-fresh
pnpm --filter @app-tour/workspace-<id> run build
node --test scripts/test/workspace-create-guest.spec.mjs
pnpm run guard:guest-plugin-conformance
pnpm run guard:guest-consumer-deps
```
