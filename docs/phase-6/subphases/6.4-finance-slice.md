### Handler flow (TourCreated → ledger outbox)

1. Outbox relay publishes `TourCreated` → `processDenaliFinanceTourCreatedRow` (same tick).
2. `tryClaimDenaliFinanceProcessedEvent` uses `processed_domain_events` with claim id `denali-finance:{domainEventId}` (separate from projection subscribers).
3. `handleTourCreatedLedgerEvent` runs when payload carries `registrationId` + `paidAmountMinor`.
4. `createPrismaDenaliOutboxWriter` enqueues `finance.ledger.double_entry_applied` in the Phase 5 outbox table (same TX boundary via `withTenantRls` + `enqueueOutboxEvent`).
5. Batch path: `processDenaliFinanceOutboxForTenant` wires `createDenaliFinanceOutboxConsumer` with Prisma reader/writer + persistent `processedStore`.
