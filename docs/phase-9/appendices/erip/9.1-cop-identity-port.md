## Enterprise standard (2026 pattern)

Production operator SaaS uses **host-bound tenant resolution → OTP challenge → DB-backed membership hydrate → synchronous CASL build** before any `(app)/` handler or protected API route. JWT payload carries identity hints only; **authorization role is always read from `UserTenant` row** (DELTA-NP-04).

## Auth flow (fail-closed — legacy parity DEC-P9-012)

Full sequence: [`OPERATOR-LOGIN-FLOW.md`](../OPERATOR-LOGIN-FLOW.md)

```text
BFF POST /api/auth/request-otp → API POST /auth/request-otp
BFF POST /api/auth/login-web-session → API POST /auth/verify-otp → Set-Cookie session (7d JWT)
GET /api/auth/membership-ability-context → API GET /auth/ability-context
redirect /dashboard

Protected API:
  parse cookie/Bearer → verify RS256 → sess_ver check → hydrateMembershipFromDb → requireOperatorSession
```

**Rejected:** Server-side session table SoT · API `/auth/logout` required · login without BFF cookie path.
