## 1. Behavioral Objective

Deliver the **Finance Command Center** — one of the most advanced operator surfaces — with **progressive rounds** so legacy parity ships first while prepayment and installments have architectural headroom (DEC-P9-016).

| Capability                   | Round | Detail                                       |
| ---------------------------- | ----- | -------------------------------------------- |
| Finance hub (tabbed)         | R1    | overview · payments · receipts · ledger link |
| Reports API                  | R1    | summary · open-payments · ledger-events      |
| Manual payments + receipts   | R1    | create debt · upload · admin review          |
| Dashboard widget             | R1    | KPI strip → hub deep link                    |
| Reconciliation triage        | R1    | settings explorer · ledger adjust            |
| Prepayment recording         | R2    | booking wallet credit · invoice balance      |
| Payment schedule persistence | R2    | generate from template                       |
| Installments board           | R3    | overdue/due/upcoming · waive/reschedule      |
| Tour payment plan template   | R3    | settings module extension                    |
| Ledger CSV export            | R4    | optional stretch                             |

**Forbidden:** Nest `apps/api/src/modules/finance/**` · finance in urban plugin (P9-F-008 · INV-P9-006).

Full domain diagram, API catalog, manifest: [`FINANCE-OPS-UX.md`](../appendices/FINANCE-OPS-UX.md).

## 3. Architecture summary

```text
Phase 6 outbox consumer (existing)
  → denali-finance adapters (reports · payments · receipts)
  → FinanceOpsManifest panels
  → app/finance command center (interim) → (app)/finance (target)
  → booking/registration financial strip (9.5 integration)
  → reconciliation triage (settings)
```

Ledger writes **only** via `finance.ledger.double_entry_applied` outbox (TQ-P9-006).
