## 1. Behavioral Objective

Ship **production-grade mobile-first operator chrome** on the Phase 2 design stack (`@app-tour/ui-primitives` + CSS Modules + design tokens). **Not** an MVP stub header.

| Deliverable        | Target                                                            |
| ------------------ | ----------------------------------------------------------------- |
| App layout         | `apps/web/app/(app)/layout.tsx` — `force-dynamic` · session guard |
| Shell chrome       | `apps/web/src/admin/shell/operator-shell.tsx` + CSS modules       |
| Mobile drawer      | `operator-drawer.tsx` — `<768px` hamburger nav                    |
| Desktop sidebar    | persistent nav `≥768px`                                           |
| Navigation         | `operator-nav.tsx` + `resolve-operator-nav.ts` (CASL-filtered)    |
| Dashboard          | `apps/web/app/(app)/dashboard/` — widget grid skeleton            |
| Session guard      | `requireOperatorSession()` in layout                              |
| Workspace branding | tenant theme via existing `ThemeProviderChain`                    |
| Wizard CTA         | “New tour” → `/tours/new` (DEC-P9-007)                            |

**Navigation targets:** Tours · Users · Bookings · Settings · Finance — links live in 9.2; page bodies stub until 9.3–9.7.

**Stack lock (DEC-P9-013):** No Tailwind · no shadcn install · shadcn blocks = layout reference only.
