## 2. Login flow (legacy parity summary)

```text
/auth/login (phone step)
  → BFF POST /api/auth/request-otp
  → OTP step
  → BFF POST /api/auth/login-web-session
  → Set-Cookie session=JWT (7d)
  → GET /api/auth/membership-ability-context
  → redirect /dashboard
```

Full spec: [`OPERATOR-LOGIN-FLOW.md`](../appendices/OPERATOR-LOGIN-FLOW.md).

## 3. Auth pipeline (API — protected routes)

```text
resolveTenantFromHost(req)
  → parseSessionCookie(req) OR verifyJwtBearer(req)  # RS256 verify
  → validate sess_ver against UserTenant.sessionVersion
  → hydrateMembershipFromDb(userId, tenantId)
  → buildTenantAuthz(auth)
  → requireOperatorSession({ auth, authz, surface })
  → runWithHttpRequestContext(req, auth, …)
  → handler
```

Unauthenticated → **401** `IDENTITY_REQUIRED` (INV-P9-007).
