## 1. Behavioral Objective

Port legacy **users directory + invites** with **four persisted team tiers** (DEC-P9-019) and **owner-only `(app)/` panel access** (DEC-P9-018).

| Capability                  | Detail                                                                          |
| --------------------------- | ------------------------------------------------------------------------------- |
| Panel gate                  | **`isOwner`** only — admin/member/viewer → login `?access=owner-only` (DEC-P9-018) |
| User directory              | List members — cursor pagination · infinite scroll · desktop table              |
| Search + sort + role filter | URL-synced (`search`, `role`, `sort`, `status`, `tab`) — **all · owner · admin · member · viewer** |
| Pending invites             | Create, revoke, resend (real OTP, R6)                                           |
| Invite accept               | `/auth/invite/[token]` flow · SMK-P9-03 · **create-only** membership (no upsert) |
| Role change                 | Owner assigns **admin · member · viewer** — **no owner grant via PATCH**        |
| Suspend / reactivate        | PATCH per row + bulk (R1 · R8)                                                  |
| Rewards modal               | discount · VIP/GOLD · labels · selectable leader (R2)                           |
| Member detail               | role-history + booking summary drawer (R7)                                      |
| Ownership transfer          | owner-only UI + API (R5)                                                        |
| Bulk actions                | suspend · reactivate · remove · role — max 50 IDs (R8)                          |
| CSV export                  | Client-side export of filtered roster                                           |
| Remove member               | `DELETE /users/{id}` — owner only; cannot remove self or owner                   |
| RBAC API                    | **`assertOwner`** on directory + mutate — rank policy for future admin panel    |
| Legacy hydrate              | `leader` → `admin` · `viewer` persisted (DEC-P9-019)                            |

**Stack lock (DEC-P9-013):** Phase 2 primitives — see USERS-DIRECTORY-UX §6.
