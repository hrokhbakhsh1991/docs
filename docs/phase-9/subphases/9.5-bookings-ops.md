## 1. Behavioral Objective

Deliver the **Registration Command Center** (DEC-P9-011) — manifest-driven operator inbox replacing legacy split between `leader/review` (approval) and flat `bookings` table.

| Capability                                            | Detail                                                                              |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Ops inbox**                                         | `(app)/bookings` — KPI strip · search · tour chips · view toggle                    |
| **Inbox table (MVP)**                                 | Sort/filter · bulk select · capacity bar per row                                    |
| **Inspection panel**                                  | Split-pane approve/reject/waitlist — sticky actions                                 |
| **Tour board (optional R4)**                          | Kanban swimlanes per tour                                                           |
| **Departure timeline (optional R4)**                  | Group by departure urgency                                                          |
| **Legacy `/leader/review` URL alias (admin session)** | `(app)/leader/review` → same shell (`scope=leader` manifest filter · not RBAC role) |
| **Member mine view**                                  | Same route — CASL restricts to own registrations                                    |
| Approve / reject                                      | Status + outbox in one transaction (P9-F-006)                                       |
| Waitlist promotion                                    | Queue or tour workspace waitlist tab (9.3)                                          |
| Manual booking create                                 | `(app)/bookings/new`                                                                |
| Tour workspace embed                                  | Registrations tab uses `BookingsCommandCenter` with `tourId` preset                 |

**Not in scope:** anonymous public POST registration (Phase 8 Urban intake) — 9.5 **operates on existing records** or operator-initiated create.
