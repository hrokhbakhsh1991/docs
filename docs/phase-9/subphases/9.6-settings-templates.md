## 1. Behavioral Objective

Deliver **manifest-driven settings** for Denali (DEC-P9-009) with **hybrid storage** (DEC-P9-010) — full legacy module inventory per DEC-P9-008 **without** copying 64 legacy files.

| Module                         | kind              | Trunk                          |
| ------------------------------ | ----------------- | ------------------------------ |
| Settings hub                   | manifest nav      | `(app)/settings` dynamic cards |
| Account prefs                  | account           | `/settings/me` (identity 9.1)  |
| equipment · themes · languages | reference_data    | generic CRUD panel             |
| locations                      | reference_data    | tabbed generic CRUD            |
| tour presets                   | reference_data    | generic CRUD                   |
| wizard template                | tenant_config     | custom builder + config router |
| advanced presets               | tenant_config     | schema form                    |
| audit trail                    | readonly_explorer | read-only explorer             |

**Urban regression:** `/urban/settings` owner-only — admin **403** (INV-P8-007). Denali manifest modules **hidden** on urban host.
