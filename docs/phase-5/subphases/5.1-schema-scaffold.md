## 2. RLS verification (manual `psql`)

Confirm **ENABLE** + **FORCE** + policy on `outbox_events`:

```sql
SELECT c.relname, c.relrowsecurity, c.relforcerowsecurity
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE n.nspname = 'public' AND c.relname = 'outbox_events';

SELECT polname,
       pg_get_expr(polqual, polrelid) AS using_expr,
       pg_get_expr(polwithcheck, polrelid) AS with_check_expr
FROM pg_policy
WHERE polrelid = 'public.outbox_events'::regclass;
```

**Expected:**

| Check                            | Expected value                                                     |
| -------------------------------- | ------------------------------------------------------------------ |
| `relrowsecurity`                 | `true`                                                             |
| `relforcerowsecurity`            | `true`                                                             |
| `polname`                        | `outbox_tenant_isolation`                                          |
| `using_expr` / `with_check_expr` | `tenant_id = current_setting('app.current_tenant_id', true)::uuid` |

## 4. Forbidden-access integration test (`app_tour` role)

**Spec:** [`apps/api/test/outbox-rls-forbidden-access.spec.ts`](../../../apps/api/test/outbox-rls-forbidden-access.spec.ts)

| Case                | Connection               | Session `app.current_tenant_id`              | Expected                   |
| ------------------- | ------------------------ | -------------------------------------------- | -------------------------- |
| Forbidden read      | `app_tour` (NOBYPASSRLS) | **unset**                                    | `findMany()` → **0 rows**  |
| Forbidden by id     | `app_tour`               | **unset**                                    | `findUnique` → **null**    |
| Allowed scoped read | `app_tour`               | **set** in same TX (`set_config(..., true)`) | Seeded tenant rows visible |

Run:

```bash
export DATABASE_URL="postgresql://app_tour:app_tour@127.0.0.1:5434/tour_db"
export DATABASE_URL_ADMIN="postgresql://postgres:postgres@127.0.0.1:5434/tour_db"
pnpm --filter @apps/api exec node --import tsx --test test/outbox-rls-forbidden-access.spec.ts
```

**Interpretation:** Any non-zero `findMany()` without `set_config` is an **RLS regression** (security failure).
