## Exit criteria

- Redis keys: `ratelimit:{tenantId}:{tier}:{route}`
- Pool vs silo tier caps from env (`RATE_LIMIT_POOL_RPM`, `RATE_LIMIT_SILO_RPM`)
- 429 response with JSON body `{ error, requestId, retryAfterMs }`
- If `REDIS_URL` unset: document BLOCKER — do not fake PASS
