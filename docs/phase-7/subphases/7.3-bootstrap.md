| `apps/api/src/tours/canonical-validation-sync.ts`      | `resolveValidationDimensions` uses `ruleSet.defaultCellId` dimensions when matrix is not `variant` or denali `category+duration` |

### Validation dimensions (urban)

Urban `ruleSet.matrixDimensions` is `["tourType"]` with default cell `city` (`dimensions: { tourType: "city" }`). Starter uses `variant` (maps to `validationVariant`); Denali uses hard-coded `category`/`duration`. For any other matrix shape, API sync validation resolves dimensions from the plugin's **default cell** so `validateCanonicalBeforePersistSync` does not emit `RULE_CONTEXT_UNMATCHED` for urban golden fixtures.
