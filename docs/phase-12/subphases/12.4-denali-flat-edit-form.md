### Legacy behaviour

1. **Hydrate:** `transformTourToDenaliWizardValues(tour)` → `DenaliCreateTourWizardForm` (RHF), not canonical draft envelope.
2. **Layout:** One `<form>`; map wizard steps **except `review`** → `<DenaliSection sectionId={…} />` (Card per section).
3. **Rules:** Same matrix + `useDenaliEditRuleSync` (visibility/required/ghost) — no step Next gate.
4. **Submit:** `updateTourDtoFromDenaliWizardForm(form, { patchIntent: "save" | "publish" })` → PATCH.
5. **Publish:** Separate intent / owner gate — not mixed into casual field edits.

### 12.4d — Edit autosave (12.3 closure)

| Task | Detail |
|------|--------|
| Key | `denaliEditTourDraftKey(tourId)` in `operator.wizard` namespace |
| Hook | `useWorkspaceDraft` + `mergeDenaliWizardDraftEnvelope` |
| UX | `DraftSyncIndicator` + `DraftConflictBanner` on edit page |
| After PATCH | Reload tour GET, then `clearDraftAndReset(seed from GET)` stamped with `meta.sourceRowVersion` |

**Draft vs canonical (edit authority):**

```text
unsaved remote draft (sourceRowVersion >= tour.rowVersion, or unstamped)
        → form shows draft (operator in-progress edits survive reload)

stale remote draft (sourceRowVersion < tour.rowVersion)
        → discard; hydrate from GET tour (saved canonical wins)

after successful save|publish|unpublish PATCH
        → GET tour, then clearDraftAndReset(GET snapshot)
        → do NOT clearDraft() to null then re-seed from React state:
          that races: the pre-PATCH tourBaseline is still in memory,
          so autosave PUT resurrected the old title over the saved one
```

`meta.sourceRowVersion` is the tour `rowVersion` the envelope was hydrated from. Unsaved field edits keep that stamp; a later PATCH increments tour `rowVersion`, so the leftover autosave snapshot is stale.

Header **ذخیره پیش‌نویس** is draft-engine flush (`DIRTY`/`ERROR` only). Footer **ذخیره تغییرات** is the tour PATCH. They are not the same control.

Authority + specs: [`wizard-experience.md`](../../workspaces/denali/wizard-experience.md) (flat edit draft authority) · `packages/workspaces/denali/test/flat-edit-draft-authority.spec.ts`.
