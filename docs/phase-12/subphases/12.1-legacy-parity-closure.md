# 12.1 — Legacy parity closure (validation + review registry + equipment API)

> **Status:** DONE — 2026-06-11  
> **Parent:** [12.0b contextual-rules-package](12.0b-contextual-rules-package.md)

## Problem

After 12.0b, `WorkspaceWizardHost` still:

1. Calls `validateDenaliWizardDraftSync` from `apps/web` (Denali validation logic in web layer).
2. Imports Denali review React (`DenaliReviewStep`, completion header, publish field) directly.
3. Filters equipment in the wizard using a single `category` column — themes already expose server-derived `compatibleCategories` (11.17); equipment did not.

## Solution

| Deliverable | Mechanism |
|-------------|-----------|
| Draft validation | `WorkspaceWizardHostHooks.validateDraftSync` — Denali impl in `packages/workspaces/denali/src/wizard/denali-wizard-validation.ts` |
| Review UI decouple | `reviewSurfaceId: "denali"` on hooks + `wizard-review-surface-registry.tsx` in web |
| Equipment catalog | `resolveEquipmentCompatibleCategories(category)` in Denali package; enrich on `GET /settings/resources/equipment` for Denali tenants |

## Hook additions (SDK)

```typescript
readonly validateDraftSync?: (input: {
  readonly plugin: WorkspacePlugin;
  readonly draft: Readonly<Record<string, unknown>>;
  readonly rulesModule: unknown;
  readonly tenantId: string;
  readonly scope?: {
    readonly stepId?: string;
    readonly visibleSteps?: readonly unknown[];
  };
}) => WizardDraftValidationResult;

readonly reviewSurfaceId?: string;
```

Host calls `wizardHost.validateDraftSync` when `usesStepValidation === true`.  
Step-nav Continue (`handleBeforeNext`) and live review both pass `evalContext` (tenant `uiOptions` / `fieldRulesOverlay`) — INV-DENALI-WIZ-014.  
Review chrome resolves via `resolveWizardReviewSurface(wizardHost.reviewSurfaceId)`.

## Equipment `compatibleCategories`

Derived from stored `category`:

- non-empty `category` → `[category]`
- null/empty → `[]` (wizard treats as universal — same semantics as pre-12.1 filter)

Web filter prefers `compatibleCategories` when present, falls back to legacy `category`.

## Acceptance

| ID | Assertion |
|----|-----------|
| SDK-12.1-01 | `validateDraftSync` + `reviewSurfaceId` on `WorkspaceWizardHostHooks` |

| WEB-12.1-01 | Host has no direct Denali review component imports |
