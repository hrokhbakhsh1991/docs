# 12.6 — Publish readiness validation matrix

> **Status:** DONE — 2026-06-11  
> **Prerequisite:** [12.5 guide languages](12.5-guide-languages-wizard.md) · Legacy `publishReadinessRules.ts`

## Problem

Flat edit **Publish** and wizard review **Active** set `publishStatus: active`, but trunk only ran `PlatformWizardEngine.validateCanonical`. Legacy also enforced the **rule-engine required matrix** (conditional required: dong, paid price, multi-day itinerary, etc.) via `collectDenaliPublishReadinessRuleIssues`.

Save-as-draft must stay lenient; publish transition must fail closed when visible required fields are empty.

## Solution

| Layer | Mechanism |
|-------|-----------|
| Rule required collector | Port `collectDenaliRuleRequiredIssues` → `rules/denaliRuleRequired.ts` |
| Publish matrix | `validation/publishReadinessRules.ts` — normalize form, resolve rule model, submit-scope required scan |
| Wizard host hook | `validatePublishReadiness` on `WorkspaceWizardHostHooks` |
| Web | Flat edit `patchIntent: "publish"` + create submit when draft `publishStatus === "active"` |

### Publish transition vs review selector

Legacy gate checked `basicInfo.publishStatus === "active"`. Flat edit keeps `draft` until PATCH — host passes `publishTransition: true` to skip that guard.

```typescript
collectDenaliPublishReadinessRuleIssues(form, ruleSet, {
  uiOptions,
  publishTransition: true,
});
```
