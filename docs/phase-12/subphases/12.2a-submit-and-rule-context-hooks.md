# 12.2a — Submit payload + rule eval context hooks

> **Status:** DONE — 2026-06-11  
> **Parent:** Phase 12.2 (denali-edit-preset-builder — in progress)

## Problem

Create flow still hardcodes Denali submit/sanitize in `apps/web`:

- `prepareDenaliTourCreatePayload` in web layer
- `buildDenaliWizardRuleEvalContext` + `denaliRuleEvalContext` prop on host
- `sanitizeDenaliWizardDraft` only callable from web adapters

## Solution

| Deliverable | Location |
|-------------|----------|
| Rule eval context builder | `denali-wizard-rule-eval-context.ts` + hook `buildRuleEvalContext` |
| Draft sanitize on change | `denali-wizard-draft-sanitize.ts` + hook `sanitizeWizardDraft` |
| Create submit payload | `denali-wizard-submit-payload.ts` + hook `prepareSubmitPayload` |
| Host prop rename | `wizardRuleEvalContext?: unknown` (replaces `denaliRuleEvalContext`) |

Web shims re-export for existing tests; `new-tour-wizard-client` calls plugin hooks.

## Hook surface (SDK)

```typescript
readonly buildRuleEvalContext?: (input: {
  readonly workspaceFormProfile?: string;
  readonly mainThemeFormProfile?: string;
  readonly fieldRulesOverlay?: Readonly<Record<string, unknown>>;
}) => unknown;

readonly sanitizeWizardDraft?: (input: {
  readonly draft: Readonly<Record<string, unknown>>;
  readonly rulesModule: unknown;
  readonly evalContext: unknown;
}) => Readonly<Record<string, unknown>>;

readonly prepareSubmitPayload?: (input: {
  readonly plugin: WorkspacePlugin;
  readonly draft: Readonly<Record<string, unknown>>;
  readonly rulesModule: unknown;
  readonly evalContext: unknown;
  readonly catalog?: {
    readonly activeEquipmentIds?: readonly string[];
    readonly activeThemeIds?: readonly string[];
    readonly selectableLeaderIds?: readonly string[];
  };
}) => unknown;
```
