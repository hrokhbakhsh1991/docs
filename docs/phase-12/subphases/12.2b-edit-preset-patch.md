# 12.2b — Edit wizard, preset prefill, PATCH submit hook

> **Status:** DONE — 2026-06-11  
> **Parent:** Phase 12.2 (denali-edit-preset-builder)  
> **Prerequisite:** [12.2a submit-and-rule-context-hooks](12.2a-submit-and-rule-context-hooks.md)

## Problem

After 12.2a, create flow is decoupled but product gaps remain:

1. `(app)/tours/[id]/edit` is **R1 title-only** — no full Denali wizard.
2. Settings **tour presets** exist but do not link into `/tours/new`.
3. Submit hook only produces **POST** `CreateTourPayload` — edit needs **PATCH** with `rowVersion`.

## Solution

| Deliverable | Mechanism |
|-------------|-----------|
| Edit draft hydrate | `denaliHydrateTourEditDraft` — canonical → wizard data (no copy suffix, no photo remint) |
| PATCH payload | `prepareTourPatchPayload` hook + `prepareDenaliTourPatchPayload` |
| Preset → wizard | `/tours/new?preset={id}` applies active preset `name` + `themeId` after template gate |
| Settings UX | Preset list links to `/tours/new?preset={id}` |

> **Correction (2026-06-11):** Edit route must **not** use `WorkspaceWizardHost`. Initial 12.2b edit-wizard wiring was **reverted**; flat edit is [12.4](12.4-denali-flat-edit-form.md). Package hooks (`hydrateEditDraft`, `prepareTourPatchPayload`) remain for flat form PATCH.

### Edit hydrate vs clone

```text
clone: normalize → copy title suffix → publishStatus=draft → gear filter → photo remint
edit:  normalize → gear filter only (preserve title + publishStatus + photo refs)
```

### PATCH body shape

Same canonical projection as create (`prepareDenaliTourCreatePayload`), wrapped:

```typescript
{
  rowVersion: number;          // from GET /tours/{id}
  schemaVersion?: number;
  roots?: readonly string[];
  data?: Record<string, unknown>;
}
```

## Hook surface (SDK)

```typescript
readonly hydrateEditDraft?: (input: {
  readonly canonicalData: Readonly<Record<string, unknown>>;
  readonly activeEquipmentIds?: readonly string[];
}) => Readonly<Record<string, unknown>>;

readonly prepareTourPatchPayload?: (input: {
  readonly plugin: WorkspacePlugin;
  readonly draft: Readonly<Record<string, unknown>>;
  readonly rulesModule: unknown;
  readonly evalContext: unknown;
  readonly rowVersion: number;
  readonly catalog?: { /* same as create */ };
}) => unknown;
```

## Preset prefill rules

| Field | Canonical path | Rule |
|-------|----------------|------|
| Title seed | `title` | Set from `preset.name` when draft title empty |
| Theme | `program.themeIds` | Set `[preset.themeId]` when theme active and draft themes empty |

Preset fetch: `GET /api/settings/resources/tour_presets` → find by `?preset=` id. Inactive or missing preset → ignore param (no error block).
