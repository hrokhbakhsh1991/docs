# 12.5 — Guide languages wizard composite

> **Status:** DONE — 2026-06-11  
> **Prerequisite:** [12.4 denali flat edit](12.4-denali-flat-edit-form.md) · Settings `guide_languages` catalog (Phase 9.6)

## Problem

Settings hub exposes `GET/POST /settings/resources/guide_languages`, but the tour wizard/edit form had **no field** to attach guide languages to a tour.

## Canonical shape (trunk decision)

| Layer | Path |
|-------|------|
| Canonical | `program.guideLanguageIds` |
| Form (RHF parity) | `programNature.guideLanguageIds: string[]` |
| Step | `denali_program` |
| Composite | `denali.guide-language-ids` |

Mirrors `program.themeIds` / `leaderUserIds` array-id pattern.

## Solution

| Deliverable | Mechanism |
|-------------|-----------|
| Registry + codegen | New field in `denaliFieldRegistryData.ts` → `pnpm run denali:codegen` |
| Web composite | Checkbox list from `GET /api/settings/resources/guide_languages` |
| Submit sanitize | `sanitizeGuideLanguageIdsOnDraft` — drop inactive/missing ids |
| Template | Optional `program.guideLanguageIds` on `denali_program` in full template |

## Acceptance

| ID | Assertion |
|----|-----------|
| DEN-12.5-01 | Codegen map includes `program.guideLanguageIds` |
| WEB-12.5-01 | Composite renders when field in render plan |
| WEB-12.5-02 | Submit filters ids to active catalog rows |
