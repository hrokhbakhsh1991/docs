# 13.0b — Workspace wizard draft envelope hooks (SDK)

> **DEC:** DEC-P13-002  
> **Status:** DONE — 2026-06-18  
> **Parent:** [Phase 13 README](../README.md) · requires [13.0 wizard-media-contract](13.0-wizard-media-contract.md)

## Problem

Denali create-wizard draft uses an envelope `{ form, meta }` persisted via `useWorkspaceDraft`, but:

- `denaliPrepareDraftEnvelope` / `denaliHydrateDraftEnvelope` live in `workspace-denali` while web pages import them directly.
- No SDK hook surface for prepare/hydrate — blocks generic create-flow shell (Phase 13.4).
- `mergeDenaliWizardDraftEnvelope` stays web-coupled until Phase 13.5 (uses `TourWizardDraft` + resume helpers).

## Solution

Opaque envelope types on SDK + optional hooks on `WorkspaceWizardHostHooks`:

```typescript
export type WorkspaceWizardDraftEnvelope<TForm = unknown> = {
  readonly form: TForm;
  readonly meta: WorkspaceWizardDraftMeta;
};

export type WorkspaceWizardDraftMeta = Readonly<Record<string, unknown>>;
```

| Hook | Purpose |
|------|---------|
| `prepareDraftEnvelope(form, meta)` | Client-side envelope before push / local edits |
| `hydrateDraftEnvelope({ remote, fallbackForm, fallbackMeta })` | Remote → client envelope (strips server-only meta) |
| `normalizeRemoteEnvelope(envelope)` | Post-fetch sanitize (Denali: re-hydrate to strip `deletedRoots`) |

**Deferred to 13.5:** `mergeDraftEnvelope` — Denali merge uses web `TourWizardDraft` + `isDraftEssentiallyEmpty`.

## Meta fields (Denali reference — not SDK-mandated)

| Field | Client | Server-only |
|-------|--------|-------------|
| `currentStepIndex` | yes | yes |
| `wizardSessionId` | yes | yes |
| `freshStart` | yes | no (OCC bypass flag) |
| `deletedRoots` | stripped on prepare/hydrate | yes (tombstones) |

`shouldBypassServerVersionAdoption` on `useWorkspaceDraft` maps to `meta.freshStart === true` (Denali: `isDenaliFreshStartEnvelope` in web until 13.5).

## Denali reference implementation

`packages/workspaces/denali/src/wizard/denali-wizard-host-hooks.ts` delegates to:

- `denaliPrepareDraftEnvelope` — `../draft/denali-wizard-draft-binding.ts`
- `denaliHydrateDraftEnvelope` — same
- `normalizeRemoteEnvelope` — `denaliHydrateDraftEnvelope(envelope, envelope.form, envelope.meta)`

No logic duplication — thin casts to `DenaliWizardDraftMeta`.

`draftTombstone` on live plugins is **runtime-only** (like `wizardHost`): stripped before wizard-engine ingress. Storage ingress tests use `pluginPayloadForStorageIngress()` (JSON round-trip) — see Phase 13.8.

## Examples

```typescript
const plugin = getDenaliWorkspacePlugin();
const env = plugin.wizardHost?.prepareDraftEnvelope?.({ data: {} }, { currentStepIndex: 0 });
// env.meta has no deletedRoots after prepare
```

```typescript

```
