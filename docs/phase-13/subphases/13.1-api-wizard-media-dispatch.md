# 13.1 — API wizard media manifest dispatch

> **DEC:** DEC-P13-003  
> **Status:** DONE — 2026-06-18  
> **Parent:** [Phase 13 README](../README.md) · requires [13.0 wizard-media-contract](13.0-wizard-media-contract.md)

## Problem

`tour-wizard-photos.routes.ts` gates upload/read on `workspaceType !== "denali"` and imports MinIO helpers directly from `@app-tour/workspace-denali`. Adding a second workspace with wizard photos would require another hardcoded branch.

## Solution

Mirror **`tourWrite`** codegen (`scripts/generate-workspace-registry.mjs`):

1. `workspace.manifest.json` → optional `wizardMedia` block (Denali only today).
2. Generated `apps/api/src/tours/workspace-wizard-media-bindings.generated.ts`.
3. `workspace-wizard-media-dispatch.ts` — `resolveWizardMediaBinding(workspaceType)`.
4. Routes use dispatch — **403 when no binding** (same codes as before).

### Manifest shape (`wizardMedia`)

```json
{
  "wizardMedia": {
    "module": "./photos",
    "workspaceTypeExport": "DENALI_WORKSPACE_TYPE",
    "maxUploadBytesExport": "DENALI_MAX_PHOTO_UPLOAD_BYTES",
    "isSessionIdExport": "isDenaliWizardDraftSessionId",
    "isDraftReadKeyAllowedExport": "isDenaliWizardDraftPhotoReadKeyAllowed",
    "putDraftPhotoExport": "putDenaliWizardDraftPhoto",
    "getSignedReadUrlExport": "getDenaliTourPhotoSignedReadUrl",
    "ensureBucketExport": "ensureMinioPhotoBucket",
    "readConfigExport": "readMinioPhotoConfigFromEnv"
  }
}
```

Workspaces without async wizard assets omit `wizardMedia` (Urban, Starter).

### Dispatch API

```typescript
export function resolveWizardMediaBinding(
  workspaceType: string
): (typeof WORKSPACE_WIZARD_MEDIA_BINDINGS)[number] | undefined;

export function workspaceSupportsWizardMedia(workspaceType: string): boolean;
```

### Denali draft read key scope

New helper in `tour-photo-object-key.ts`:

```typescript
isDenaliWizardDraftPhotoReadKeyAllowed(tenantId, storageKey)
// true when key starts with `{tenantId}/wizard-drafts/`
```

Replaces inline prefix check in routes — binding owns scope rules per workspace.

## Behavior parity (13.1)

| Check | Before | After |
|-------|--------|-------|
| Non-denali tenant | 403 `WIZARD_PHOTO_*_FORBIDDEN` | 403 (no binding) |
| Denali upload | `putDenaliWizardDraftPhoto` | same via binding |
| Denali signed URL | prefix `wizard-drafts/` | `isDraftReadKeyAllowed` |
| Session / photo id | UUID regex in route | `isSessionId` from binding |
| Error mapping | `mapWizardPhotoError` | unchanged in route |
