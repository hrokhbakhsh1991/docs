# 13.3 — API validation dimensions via wizardHost hook

> **DEC:** DEC-P13-005  
> **Status:** DONE — 2026-06-18  
> **Parent:** [Phase 13 README](../README.md) · requires [12.0 wizard-plugin-hooks](../../phase-12/subphases/12.0-wizard-plugin-hooks.md)

## Problem

`canonical-validation-sync.ts` branches on `plugin.id === "denali"` and imports `resolveDenaliWizardDimensionsFromTourKind` from `@app-tour/workspace-denali`. API host should not know product ids for matrix resolution — Denali already exposes `wizardHost.resolveMatrixDimensionsFromDraft` (Phase 12.0).

## Solution

Replace product branch with optional hook (same pattern as web `workspace-wizard-host.tsx`):

```typescript
const resolveFromDraft = plugin.wizardHost?.resolveMatrixDimensionsFromDraft;
if (
  resolveFromDraft != null &&
  matrix.includes("category") &&
  matrix.includes("duration")
) {
  return { ...resolveFromDraft(data ?? {}, null) };
}
```

| Workspace | Matrix | Resolver |
|-----------|--------|----------|
| Denali | `category` × `duration` | `denaliWizardHostHooks.resolveMatrixDimensionsFromDraft` |
| Urban | `tourType` | `defaultCell` / variant paths (unchanged) |
| Starter | `variant` | `validationVariant` branch (unchanged) |

**Remove:** `@app-tour/workspace-denali` import from `canonical-validation-sync.ts`.
