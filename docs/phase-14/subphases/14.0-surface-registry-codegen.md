# 14.0 — Surface registry codegen

## Charter

Replace static workspace imports in wizard surface registries and API host wiring with manifest-driven codegen (`workspace.manifest.json` → `scripts/generate-workspace-registry.mjs`).

**Platform note:** Denali is the first product workspace plugin, not the platform name. Host code (`apps/web`, `apps/api`) must stay workspace-agnostic; product code lives under `packages/workspaces/<id>/`.

## Manifest blocks

### `wizardSurfaces` (web composite/review)

### `events[].hostSideEffect` (API outbox host adapter)

Declares the host-side runner for domain events. Replaces hardcoded `HOST_OUTBOX_SIDE_EFFECT_ADAPTERS` in codegen.

```json
"events": [{
  "eventType": "TourCreated",
  "module": "./finance/tour-created-ledger",
  "export": "handleTourCreatedLedgerEvent",
  "workspaceTypes": ["denali"],
  "hostSideEffect": {
    "adapterModule": "./finance/api-tour-created-adapter",
    "export": "runTourCreatedFinanceSideEffect"
  }
}]
```

Generated: `apps/api/src/workspace/workspace-outbox-side-effects.generated.ts` imports from `@app-tour/workspace-<id>/<adapterModule>`.
