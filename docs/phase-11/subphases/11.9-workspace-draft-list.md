## Goal

Operator shell can discover **which draft keys exist** for the signed-in user in a workspace without downloading every JSON blob. Full payloads remain on `GET …/drafts/{namespace}/{key}`.

## HTTP contract

```http
GET /workspaces/{workspaceId}/drafts?namespace=operator.wizard
```

### Auth & scope

Same as 11.2 single-draft routes: `requireOperatorSession` + `workspaceScopeMatches`.

### Response `200`

```json
{
  "items": [
    {
      "draftNamespace": "operator.wizard",
      "draftKey": "denali-create",
      "version": 2,
      "schemaVersion": 1,
      "lastModified": 1718000000100,
      "updatedAt": "2026-06-10T12:00:00.000Z"
    }
  ]
}
```

- Sorted by `updatedAt` descending (most recently touched first).
- Empty list → `200` with `"items": []` (not 404).
