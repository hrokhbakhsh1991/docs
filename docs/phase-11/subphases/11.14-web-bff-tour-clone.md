# Subphase 11.14 — Web BFF tour clone proxy

> **Authority:** [`subphases/11.12-server-tour-clone.md`](11.12-server-tour-clone.md) · **DEC-P11-012**

## Goal

Expose server one-shot duplicate to the operator shell via `POST /api/tours/{tourId}/clone` — session-forwarding BFF to `POST /tours/{tourId}/clone` on `@apps/api`.

Wizard duplicate (`/tours/new?clone=`) remains the default list CTA; BFF is for automation, future «duplicate in place» UX, and integration tests.

## Contract

| Layer | Path |
| ----- | ---- |
| Browser | `POST /api/tours/{tourId}/clone` |
| Upstream | `POST /tours/{tourId}/clone` |
| Auth | `readSessionTokenFromRequest` → `Authorization: Bearer` |
| Body | Optional `{ activeEquipmentIds?: string[] }` passthrough |
| Success | `201` — `{ id, tenantId, canonical }` |
