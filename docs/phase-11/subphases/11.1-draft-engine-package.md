# 11.1 — `@app-tour/draft-engine` (generic OCC draft sync)

> **وضعیت:** DONE (2026-06-11)

> **DEC:** [`../appendices/IMPLEMENTATION-DECISIONS.md`](../appendices/IMPLEMENTATION-DECISIONS.md) DEC-P11-002

## هدف

موتور headless برای autosave + optimistic concurrency + conflict strategies — **بدون** domain Denali. قابل استفاده در ویزارد، settings form، یا هر workspace flow.

## مرز import

| ماژول | وابستگی مجاز |
| ----- | ------------- |
| `@app-tour/draft-engine` | فقط Node/browser timers — **بدون** React |
| `@app-tour/draft-engine/react` | `react` (peer) + core |

`packages/draft-engine` → **ممنوع** import از `packages/workspaces/*`، `apps/*`، `platform-core`.

## API surface

### Types (`DraftStatus`)

`IDLE` · `SYNCING` · `DIRTY` · `DRAFT_AVAILABLE` · `CONFLICT_RESOLVING` · `ERROR`

### `DraftEngine<T>`

- `initialize()` — `onFetch` → hydrate
- `setDraftData(data, { source: 'user' \| 'remote', version?, ... })`
- `subscribe(listener)` — pub/sub state
- `retry()` · `applyDraft()` · `clearDraft()` (نیاز `onDelete`)
- debounce پیش‌فرض **500ms** (`debounceMs` config)

### Conflict strategies

`SERVER_WINS` · `CLIENT_WINS` · `MERGE` · `REFETCH_REAPPLY`

`DraftConflictError` — `onPush` با version mismatch پرتاب می‌کند.

### React

`useDraftEngine(config)` از `@app-tour/draft-engine/react` — hook با live config ref.
