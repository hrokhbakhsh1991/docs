    Interface WorkspaceCapabilities

    UI capability flags for a workspace tour form profile. Call sites should use these instead of profile === "…" or raw wizard mode strings.

    Derived from the same sources as API WorkspaceStrategyRegistry builders (getTourFormProfileDescriptor + getTourWorkspaceDefinition).
