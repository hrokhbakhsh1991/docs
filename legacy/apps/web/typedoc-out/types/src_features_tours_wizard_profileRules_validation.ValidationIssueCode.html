    Type Alias ValidationIssueCode

    ValidationIssueCode: "required" | "shape"

    Pure 3-level validation for the Tour Creation Wizard. Each level consults the rules table via isFieldRequiredAtLevel / getStepRules — there is no hard-coded list of required fields here.

    Levels:

    • Autosave — never enforces required. Uses getStepRule / getStepRules so the caller is scoped to the current wizard step; returns isValid: true in v1 so legacy drafts are never blocked. Reserved for visibility-aware shape-only checks.

    • Step navigation — required fields whose belongsToStep matches the step being left, when that step is visible for the profile. Uses isFieldRequiredAtLevel(..., "stepNav", ...).

    • Final submit — every profile-visible required field at "submit" level.

    Cross-field invariants (e.g. private_car + supplementalPrivateCar) stay in Zod only until M6.
